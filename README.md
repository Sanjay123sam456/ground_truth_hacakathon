# 🚀 InsightBot — Automated CSV-to-PDF Insight Engine

**Tagline:**
Transform raw CSV data into **executive-ready PDF reports with AI-generated insights in seconds.**

---

# 📌 Problem

In many analytics workflows, analysts and account managers spend hours:

* Cleaning CSV files
* Extracting insights
* Formatting reports for stakeholders

This manual process is:

* ⏳ **Time-consuming**
* ⚠ **Error-prone**
* 📉 **Slow for decision-making**

Important patterns like **traffic drops, campaign performance changes, or regional sales anomalies** can go unnoticed.

---

# 💡 Solution

**InsightBot** automates the entire analytics reporting pipeline.

Users simply upload a CSV file and the system automatically:

1️⃣ Processes the dataset
2️⃣ Generates a structured data summary
3️⃣ Uses AI to extract key insights
4️⃣ Produces a **professionally styled PDF report**

All within **seconds**.

---

# ⚙️ System Workflow

```
CSV Upload
     ↓
Data Processing (Pandas)
     ↓
Data Summary Generation
     ↓
AI Insight Generation (Google Gemini)
     ↓
Markdown → HTML Conversion
     ↓
Styled PDF Report Generation
```

---

# 📊 Output

The generated **PDF report** includes:

* 📈 Data summaries and key metrics
* 🤖 AI-generated analytical insights
* ⚡ Highlighted trends or anomalies
* 📊 Clean tables formatted for readability

Example insight generated by the system:

> "Clicks dropped by 30% in Chicago last week, suggesting a potential campaign performance issue."

---

# 🧠 Technical Architecture

### 1️⃣ Data Ingestion

Users upload a CSV file or paste raw tabular data.

### 2️⃣ Data Processing

The dataset is loaded and optionally filtered using **Pandas**.

### 3️⃣ AI Insight Generation

A structured prompt is built containing:

* summarized dataset context
* key metrics
* filtered data

This prompt is sent to **Google Gemini LLM** to generate insights grounded in the data.

### 4️⃣ Report Generation

The AI response is converted using the following pipeline:

```
Markdown → HTML → Styled PDF
```

Libraries used:

* `markdown2` for Markdown conversion
* `WeasyPrint` for PDF generation

### 5️⃣ User Interface

The **Streamlit web app** provides:

* CSV upload interface
* data preview
* AI-generated insights
* PDF preview
* report download button

# ⚠ Challenges & Learnings

### 1️⃣ AI Hallucinations

**Problem:**
The LLM occasionally generated insights not present in the dataset.

**Solution:**
Implemented strict system prompts and passed only the **filtered dataset summary** as context.

---

### 2️⃣ Markdown to PDF Conversion

**Problem:**
The AI returned insights in Markdown format.

**Solution:**
Converted Markdown to HTML using `markdown2`, then generated the final PDF using `WeasyPrint`.

---

### 3️⃣ PDF Styling Issues

**Problem:**
Tables and formatting initially appeared misaligned.

**Solution:**
A consistent CSS template was applied to ensure **clean, professional report formatting**.
